# 尚行 · GDUFS Wayfinder　本地客户端　使用说明

> 广东外语外贸大学第二届 AI 应用创新大赛　参赛作品
> 版本：1.0　｜　更新：2026-10-21

---

## 一、这是什么

广外校园导航与办事指南。核心是一个 **1.7 MB 的单文件网页**，里面包含了：

- 3D 校园地图（南校区 51 栋 LOD2 模型 + 北校区 42 栋，路网 220 节点）
- 40 条办事事项（部门、地点、时段、材料、电话）
- 中英双语界面
- 本地问答（离线可用）

**不需要安装 Node、Python、数据库，不需要联网。**

---

## 二、怎么运行（2 步）

1. 把压缩包解压到任意目录（路径里最好不要有空格）
2. 双击 **`启动.cmd`**（它打开的是同目录的 `index.html`）

浏览器会自动打开。如果系统拦截了 `.cmd`，直接双击 `index.html`
或 `尚行-广外校园向导.html` 也一样（两个文件内容完全相同，只是文件名一个英文一个中文）。

> 推荐用 Chrome / Edge。IE 和很老的 Safari 不支持 WebGL，会白屏。

## 三、能做什么

| 功能 | 离线可用 | 说明 |
|---|---|---|
| 3D 地图浏览、旋转缩放 | ✅ | 左键拖动旋转，滚轮缩放，右键平移 |
| 建筑点选、信息卡 | ✅ | 点任意建筑看名称、类型、层数 |
| 路线规划（起终点下拉框） | ✅ | 内置 Dijkstra，真实路网，含地下隧道 |
| 第一人称漫游 | ✅ | 点「走过去看看」，沿路线走，1.4 m/s，ESC 退出 |
| 办事卡片（部门/地点/材料/电话） | ✅ | 40 条事项，可一键导航到楼栋 |
| 中英切换 | ✅ | 右上角 中/EN |
| **AI 对话（语心）** | ⚠️ | 需要能访问校内 `172.17.1.46`；连不上会自动降级为本地规则问答 |

**断网时**：地图、路线、漫游、办事卡片、双语全部正常；只有"问一句话让它理解"的能力降级为关键词匹配。

## 四、连不上 AI 怎么办

页面右下角的语心面板，如果徽章显示「离线 · 本地规则」，说明没连上 Dify。三种情况：

1. **不在校园网**：接上校园 WiFi 或 VPN 再刷新
2. **校内网但服务换了地址**：编辑 `ai-config.js`（在网页源码里，搜 `GDUFS_AI`），把 `base` 改掉后重新打包；或用 `?ai=off` 强制离线
3. **就想演示离线**：直接用，不影响其余功能

## 五、常见问题

**Q：打开是白屏？**
A：浏览器不支持 WebGL。换 Chrome / Edge，或在设置里打开"硬件加速"。

**Q：地图转不动？**
A：先点一下画面再拖。如果开了漫游模式，按 ESC 退出。

**Q：办事信息是准的吗？**
A：来自 11 个院部官网的一手页面，标注了来源链接。官网没公布的会明确写「官网未公布」，不会编造。

**Q：北校区怎么进？**
A：右上角切「北校」，或者地址栏加 `?campus=north`。

**Q：想直接看英文版？**
A：右上角切 EN，或者地址栏加 `?lang=en`。

## 七、技术说明（给评委）

- 前端：Three.js r128 + 自研渲染管线，无构建步骤
- 3D 模型：Blender 4.5 无头脚本生成，导出 glTF 2.0（GLB 内联为 data URI）
- 路网：OpenStreetMap 步行道 + 校内道路，220 节点 / 239 边
- 北校区：学校官方平面图矢量化，400 米跑道标定 0.4178 米/像素
- 智能体：Dify 1.17.1 Chatflow（意图路由 + 导航/办事/百科 三专家 + 4 个 Skill）
- 模型：DeepSeek-V4-Flash-0731（2026-10 起切换至 DeepSeek-V4.1-Flash-1017-w8a8）
- 数据来源：11 个院部官网、广州市规划验收合格证、OpenStreetMap/Overture、学校官方平面图
