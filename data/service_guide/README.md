## 7. 建议如何补齐

1. **人工过验证码**：由有浏览器会话的同事下载上述附件（一次性），再用 `python-docx` / `pdfplumber` 抽正文。这是把 3 条“低”升为“高”的最短路径。
2. **优先补 3 条低置信度**：转专业（学籍科）、辅修/双学位（教务科）、勤工助学（资助中心）——官网均无流程页，只能电话或现场索取，建议以“电话核实”作为来源并标注日期。
3. **图片类继续 OCR**：图书馆楼层指引 pdf、云山会堂使用流程、财务票据粘贴指引（图）尚未处理。
4. **电话核验清单**：财务部咨询电话与房间号、国际部项目电话、就业中心房间号、校医院普通门诊时段。
5. **时效性绑定**：选课、缴费、四六级、交换生均为“按学期/学年”发布，入库时应加“适用学年”字段，避免把 2026 年时间当长期规则。

## 8. 使用与合规提示

- `sources` 全部为 *.gdufs.edu.cn 页面；OCR 字段已在条目内注明“据图片 OCR，需核对”。
- `confidence=低` 的条目请勿直接对外答复。
- 建议 RAG 分块：一条事项一个 chunk；lite 版可直接用 `title + department + location + phone` 做元数据过滤。
