# 广外南校区 3D 导航

基于 `gdufs-south-campus/` 资料包 + 广外官方资料构建的**校园 3D 导航**页面：真实建筑轮廓 + 程序化立面/屋顶 + 步行路径规划。

## 打开方式

**双击 `index.html`** 即可（Chrome / Edge / Firefox，需 WebGL）。

Three.js 已放在 `vendor/`，**完全离线可用**，不依赖 CDN。

操作：

- 左键拖动旋转 · 滚轮缩放 · 右键平移
- 左上角下拉框选择起点 / 终点
- 也可直接**点击画面中的建筑**：第一次点=起点，第二次点=终点，再点重新开始
- 右下角指北针随视角旋转，默认视角正北朝上
- 按钮：建筑标注 / 道路 显隐、重置视角

### 两种运行模式

| 打开方式 | 结果 |
|---|---|
| 双击 `index.html`（`file://`） | 浏览器会拦截 GLB 的 fetch，**自动降级**为程序化几何，功能完整 |
| `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/gdufs-3d/index.html` | 加载 `assets/gdufs_buildings.glb`，看到 Blender LOD2 模型 |

### 单文件版（交付/演示用）

`dist/广外校园向导.html`（约 1.47 MB）把 three.js、所有数据脚本和 GLB（base64 内联）打进一个 HTML：

- 双击即可打开，**不需要服务器**，也不受 `file://` 限制；
- 可以直接上传到任何静态托管（GitHub Pages / Vercel / 校内服务器），当成"可公开访问的作品链接"；
- AI 面板仍然优先连 Dify，连不上自动回落本地规则。

重新打包：`node tools/build_single_file.mjs`（改完源码后跑一次）。

## AI 校园向导（Dify Chatflow）

右下角面板「校园向导」接的是 Dify 应用「广外校园向导」（Chatflow + 两个知识库）。

| 问什么 | 效果 |
|---|---|
| 从文采园怎么去图书馆？ | 意图识别为导航 → **地图上直接画出 820 m 路线**，相机飞到路线中点 |
| 成绩单在哪里办？ | 检索办事指南库 → 回答 + 卡片（部门/地点/材料/电话 + 官网链接） |
| 第一饭堂几点开门？ | 检索校园百科库 → 回答 + 卡片 + 定位到文采园 |

- 配置在 `ai-config.js`（`base` / `key` / `timeout`），密钥是 WebApp 级别的，只能调这一个应用。
- **多轮对话**：前端会带 `conversation_id`，Dify 两个 LLM 节点已开记忆窗口。
  实测「从文采园怎么去图书馆？」→「那从图书馆再去二饭呢？」能正确接上。
- **离线兜底**：Dify 不可达时自动切到本地规则（地名匹配算路 + `faq-data.js` 里 40 条 FAQ 关键词检索），右上角徽章会显示「在线 · Dify」或「离线 · 本地规则」。
- 契约：Dify 返回 `{intent, from, to, answer, card}`，前端只负责执行动作，不依赖模型说话准不准。

搭建与复现见 [`../docs/04-Dify应用搭建记录.md`](../docs/04-Dify应用搭建记录.md)。

## 三维表达（2026-10 升级）

| 项 | 做法 |
|---|---|
| 立面 | 按轮廓逐边生成带 UV 的墙面，1 张贴图 = 3.6 m 开间 × 3.6 m 层高，窗格随楼长/楼高自动缩放 |
| 立面原型 | 教学/实验楼（米白瓷砖+红褐砖柱+横向带窗）、图书馆（红褐石材+青绿玻璃幕墙）、宿舍（暖米色+白色窗台方窗）、食堂（砖红墙垛+通高玻璃）、体育馆（浅灰金属板） |
| 屋顶 | 0.9 m 女儿墙 + 按 id 稳定生成的屋顶设备箱（2–4 个/栋） |
| 植被 | 1 008 棵行道树/绿地乔木，`InstancedMesh` 渲染，自动避让建筑与校门 |
| 校门 | 双门柱 + 横梁 + 地面标识 |
| 色彩 | Three.js r128 无色彩管理，纯色材质统一做 `convertSRGBToLinear()`；`ACESFilmic` 色调映射 |

立面配色依据官方校园风光照片：`../data/official/g_building.jpg`（教学楼群与钟楼）、`../data/official/g_lbnight.jpg`（图书馆）。

## 数据来源与建模方法

数据来自 `gdufs-south-campus/04_gis/`：

1. `buildings.geojson` — 45 个建筑体块**真实轮廓多边形**（EPSG:4326）
2. `roads.geojson` — 85 条校园及周边道路
3. `landscape.geojson` — 水系、绿地、运动场
4. `campus_boundary.geojson` — 校园边界
5. `pois.geojson` — 校门 / 入口

转换脚本 `gdufs-south-campus/scripts/build_nav_data.py`：

- 用 pyproj 把 EPSG:4326 投影到 **EPSG:32649（UTM 49N）**，再减去模型原点
  （E 745081.015, N 2552892.658），得到局部米制坐标；
- **沿 x 轴镜像**：使正北朝上时东在右侧（与常规地图、官方标注图一致）；
- **拆分连体体块**：源数据中「实验楼A–E区」「教学楼E/F/G栋」各是一个连体多边形，
  脚本按主轴垂直切口拆成单栋；
- 多边形用 shapely 简化到 0.4 m 容差，闭合环校验通过；
- 输出 `gdufs-data.js`（约 86 KB）。

**名称/层数/高度修正**：`../tools/patch_data.mjs`（幂等，可重跑）。依据见
`../docs/02-三维模型修正与视觉升级.md` 与 `../data/official/`。

## 寻路原理（沿道路网络 + 隧道唯一跨路）

1. 从 `roads.geojson` 构建**道路拓扑图**：裁剪到校园范围外扩 45 m，
   用 `unary_union + linemerge` 在交叉口打断并合并成路段，端点 2.5 m 内合并为同一节点；
2. **南北唯一通道**：取南北两块校区范围各外扩 45 m 的重叠走廊作为「地面屏障」，
   所有地面道路在该走廊内被切断，只保留 OSM 中 `tunnel=yes` 的地下隧道及其步行引道；
3. 每个建筑 / 校门：取**最近的道路点**，在该处切开路段建立接入节点，
   再从道路点接一段到建筑外轮廓（门/接驳段），保证所有地点都接入主路网；
4. 用 **Dijkstra** 在道路图上求最短路径（注释写作 A*，实为 Dijkstra），路径严格沿路段折线绘制；
5. 距离 = 沿道路长度（含接入接驳段）；明显转角用黄色圆点标出；
6. 路线经过隧道时，状态栏会标注「经地下隧道穿行」，隧道在图中以青色半透明带 + 两端入口环表示。

当前图规模：220 个节点 / 239 条边 / 48 个可选地点（44 栋命名建筑 + 4 个已定名校门）。

### 校门（按官方平面图命名）

官方迎新网平面图（<https://yx.gdufs.edu.cn/n.jpg>）只标注 **6 个出入口**；官方从未使用"东门/南门/西门/东北门/西北门"。

| 官方名 | 位置 | 坐标 (x=西正, z=北正) | 依据 |
|---|---|---|---|
| 正门 | 东北角，外环东路 | (−251, 192) | OSM 门位 |
| 行政出入口 | 东南侧，外环东路 | (−375, −220) | OSM 门位 |
| 1号门 | 中部，中环路（文采园与隧道之间） | (−7, −170) | OSM 门位 |
| 2号门 | 外环东路南段，友苑南侧 | (−25, −576) | 道路×边界交点（推算） |
| 3号门 | 西侧，外环西路（学生活动中心旁） | (197, −474) | OSM 门位 |
| 4号门 | 西南角，内环东路（风采园旁） | (284, −706) | 道路×边界交点（推算） |

> 2/4 号门是推算值（`name_confidence: "inferred"`），现场核对后改 `x/z` 即可。
> 旧版"北门""西北门""西南门""生活区4号门"等称谓是按方位自拟的，已废弃。

### 水系

- 河道/水渠：来自 OpenStreetMap（`waterway=river/canal`），9 条线、63 个点，渲染成 7–11 m 宽水带。
- **语心湖**：OSM `relation/19177031`（`water=lake`，184 个顶点），另含体育场东侧湖面（`relation/19159564`）。
- 树木生成时会避开水面（1 008 → 975 棵）。

**连通性验证**：移除隧道区域后，南北校区 36 组起终点组合全部不可达；保留隧道后 9 组全部可达。
即隧道是南北之间唯一的地面通道。

## 精度与已知限制

1. **高度**：图书馆（6 层/25 526 ㎡）、大会堂（2 层/8 375 ㎡）、艺术楼（5 层）、院系办公楼（4 层）、
   学术交流中心（6 层）、体育馆（3 层）按**广州市规划验收合格证**修正；
   其余教学楼/实验楼/行政楼/看台仍为**类型估算**（教学楼 E 栋 5 层为唯一硬证据）。
2. **轮廓为体块级**：「实验楼A–E区」「教学楼E/F/G栋」是连体体块，本模型按主轴等分拆分，
   切口位置为几何等分、非实测分界；**实验楼 A–E 的区号方向已用官方平面图逐栋核对通过**
   （E→D→C→B→A 由北向南）。
3. **寻路依赖 OSM 道路/步行道数据**：OSM 未覆盖的小径、楼间连廊可能缺失，
   个别建筑与道路之间用直线接驳段连接；道路属性（是否可步行、是否台阶）未全部参与判断。
4. **隧道走向来自 OSM**：按 `tunnel=yes` 的步行隧道建模，长度约 70 m、连接生活区与教学区；
   隧道实际入口位置与内部走向请以现场为准。
5. **立面为程序化生成**：窗格密度、色彩按建筑类型与官方照片推定，不是逐栋实测立面。
6. **2/4 号门坐标为推算值**：由道路与校园边界的交点推得，待现场核对。
7. **语心湖水面缺失**：OSM 未测绘湖面多边形，官方平面图无坐标系统，暂留空。
8. **不是测绘成果**：不能用于报建、消防、日照、造价等用途。
