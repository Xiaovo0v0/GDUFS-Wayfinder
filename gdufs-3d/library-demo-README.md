# 广外图书馆 3D 识别 Demo（白天外景版）

> 目标不是“测绘复刻”，而是**让观众在几秒内认出“这是广外图书馆”**。
> 打开方式：双击 `gdufs-3d/library-demo.html`。保持 `vendor/` 在同一目录；不需要服务器，不需要联网。

## 这一版按两张白天外景照片改了什么

| 之前（夜景版） | 现在（白天版） |
|---|---|
| 红褐色石材 | **米黄色石材**，大板缝 |
| 深色屋顶 + 深色檐口 | **浅灰金属大挑檐 + 白色檐口/吊顶** |
| 左侧凸出玻璃盒 | **左侧 4 层实墙 + 金色竖排“圖書館”** |
| 中部青绿幕墙 | **中部 4 层玻璃幕墙 + 4 根银色圆柱 + 白色雨棚** |
| 右侧红石开小窗 | **右侧 6 层竖向白色遮阳鳍 + 深色玻璃** |
| 深色广场 + 晚霞 | **红砖广场 + 浅色中轴步道 + 蓝天白云** |

左侧体量 4 层、右侧 6 层，是按照片里的高低关系；规划验收证给的是整栋“地上 6 层 / 25 526 ㎡”，不区分左右两段。27 m 是右侧 6 层的模型高度，19.5 m 是左侧 4 层的模型高度，都是按 4.5 m 层高推的，不是证书原文。

## 它抓的识别特征

1. **米黄石材 + 金色竖排“圖書館”**：左侧实墙，字直接挂在墙上。
2. **四根银色圆柱**：中部玻璃幕墙前，撑住大挑檐。
3. **右侧整片竖向白鳍**：6 层高，鳍后是深色玻璃，形成很强的竖向肌理。
4. **浅灰大挑檐**：左低右高，檐口薄而亮，檐底是浅色吊顶。
5. **红砖广场 + 浅色中轴步道**：从广场正中对准入口台阶。

## 明确没做

- 室内楼层、房间、电梯/楼梯的真实位置；
- 逐点测绘、竣工图级尺寸；
- 北校、周边建筑、真实路网；
- 照片级材质（PBR 贴图、实拍立面投影）。

## 想继续改，从哪里下手

| 想改什么 | 改哪里 |
|---|---|
| 初始视角 | `camera.position.set(...)`、`controls.target.set(...)` |
| 石材/玻璃/砖 | `beigeTex`、`glassTex`、`finGlassTex`、`brickTex` |
| 左/右体量高度 | `19.5`（左）与 `27`（右）相关的 `wall(...)`、`roofSlab(...)` |
| 圆柱/竖鳍 | 四根柱子的 `for (const x of [...])`；`finXs` 的起点/终点/间距 |
| 金色字 | `signTex` 的字体与字符；`sign` 的位置 |
| 广场/树/灯 | `walkway`、`palm(...)`、`tree(...)`、`lamp(...)` 的坐标 |

## 已经接入原地图（南校 B002）

- `index.html` 在 `app.js` 之前加载 `library-model.js`。
- `app.js` 里：南校 B002 跳过旧的程序化体块；GLB 里的 B002 网格隐藏；地标模型放在 `(94.3, 0, 117)`，`scale(0.9, 1.0, 1.8)`，正面朝南（默认相机方向），主体向北落进 B002 轮廓。
- 地标模型内部把 x 镜像了一次（地图的 x 是“西为正”的镜像坐标），让“左石材/右竖鳍”在默认南向视角下仍与照片同向；金色字、无障碍牌、后门放在未镜像的 root 上，文字不会反。
- 点击、建筑卡片、路线仍然走 B002；北侧 `access` 点 `(83, 179)` 加了一个后门，路线终点不会落在光墙上。
- 单文件 `dist/广外校园向导.html` 需要重跑 `node tools/build_single_file.mjs` 才会包含新馆；当前会话的 shell 坏了，没有替你重打。

## 已知限制

- 参考面板引用的是对话里两张图的本地缓存路径；换机器或缓存清理后会回落到 `../data/official/g_lbnight.jpg`（夜景），不影响 3D 场景；
- 页面依赖 `vendor/three.min.js` 与 `vendor/OrbitControls.js`；
- 建筑背面/庭院是简化处理，绕到背面会看到比正面更“素”的墙；
- 立面是程序化纹理，近看能看出重复。
