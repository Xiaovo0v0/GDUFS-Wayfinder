## 一、模型下线与切换

### 现状

| 模型 | 状态 | 掌握在谁手里 |
|---|---|---|
| DeepSeek-V4-Flash-0731 | **本周五晚间下线** | 我们 5 个应用全在用 |
| GLM-5.2 | 同批下线 | 未使用 |
| Qwen3.8-27B | 保留 | 可作为备用 |
| DeepSeek-V4.1-Flash-1017-w8a8 | 新上线（量化版、支持视觉） | **控制台里还没有这一条** |

### 关键发现

模型网关是学校统一提供的 `https://modelsq.gdufs.edu.cn/v1-openai`，Dify 里那个
`OpenAI-API-compatible` 供应商就是指向它。新增模型**必须在 Dify 里手动加一条**，
并且加的时候要再填一次 **API Key**（控制台里存的是加密的，看不到明文）。

我们试过直接调控制台接口创建：

```
POST /console/api/workspaces/current/model-providers/{provider}/models
{ "model": "DeepSeek-V4.1-Flash-1017-w8a8", "model_type": "llm", "credentials": {} }
→ 200 {"result":"success"}
```

接口返回成功，但模型列表里**没有出现**——这条路径要求带凭据，纯接口加不进去。
所以必须在界面上加，或者拿到网关的 API Key。

### 三条路，按优先选一条

**① 推荐：界面上加（4 步，1 分钟）**

1. 打开 http://172.17.1.46/integrations/model-provider
2. `OpenAI-API-compatible` 卡片上点 **添加模型**
3. 填：模型名称 `DeepSeek-V4.1-Flash-1017-w8a8`、模型类型 `LLM`、
   API Key（学校发的那个 `sk-...`）、Base URL `https://modelsq.gdufs.edu.cn/v1-openai`
4. 点 **添加** → 列表里出现即可

**② 有 API Key 的话，一条命令切完**

```bash
node tools/dify_switch_model.mjs DeepSeek-V4.1-Flash-1017-w8a8
```

脚本会：换模型名重新生成 DSL → 导入 → 发布 → 建密钥 → 改 `ai-config.js` → 重打单文件。
跑完把新 appId 写进文档，再用 `tools/dify_cleanup.mjs` 删掉旧应用。

**③ 兜底：切到 Qwen3.8-27B（不用加模型，现在就能用）**

```bash
node tools/dify_switch_model.mjs Qwen3.8-27B
```

实测过，能跑，但有两个毛病：
- **慢 3–5 倍**：导航 24s、办事 36s、百科 15s（DeepSeek 是 4/7/3.5 秒）
- **会输出 `<think>` 推理过程**，把 JSON 挤到后面

前端已经加了兜底：解析前先剥掉 `<think>…</think>`，剥完再找 JSON；
真解析不出也不会把推理过程甩给用户。所以切 Qwen 不会崩，只是变慢。

> 周五之前不必动。现在线上跑的仍是 DeepSeek-V4-Flash，一切正常。

## 二、提交形式怎么填

通知原文：**优先在线演示地址**；无公网部署能力的，填「本地客户端应用」，
且必须附**安装包**+**README.md**；主办方如需核验后台会另行通知。

### 我们的实际情况（如实说）

| 部分 | 现状 | 是否公网可达 |
|---|---|---|
| 智能体（Dify） | 学校服务器 `172.17.1.46` | ❌ 校内网 |
| 3D 前端 | 开发机 `python -m http.server`（8080） | ❌ 局域网 |
| 单文件版 | 一个 1.7 MB HTML，双击即开 | ✅ 任何地方（本地打开） |

**结论：我们没有公网部署能力。** 172.17.1.46 是校内私有地址，评委在校外打不开。

### 建议填法（二选一，看收集表字段）

## 三、本地安装包要做成什么样

通知要求"打包完整的环境，下载后仅需少数步骤即可完成部署并运行"。我们要交的是：

```
尚行-本地客户端/
├── 尚行-广外校园向导.html      ← 双击就能用，3D 地图 + 本地问答全在里面
├── 启动.cmd                    ← 可选：起一个本地小服务，行为与线上完全一致
├── README.md                   ← 安装与使用说明（必交）
└── 演示视频.mp4                ← 可选
```

**"完整环境"的说明**：前端零依赖（Three.js、模型、路网、办事数据全部内联进那一个 HTML），
不需要装 Node、不需要装 Python、不需要联网。这比"打包一个 Python 环境"更彻底，也更好演示。

唯一需要注意的是：**AI 对话需要校内网**才能连 Dify；纯离线时走本地规则（地名匹配 + 40 条 FAQ），
地图、路线、漫游、办事卡片**全部正常**。
