## 二、把作品发布到公网（三选一）

### 方案 A：Vercel 拖拽部署（最快，1 分钟）

1. 打开 <https://vercel.com/new>，登录（GitHub / 邮箱均可）；
2. 把 `gdufs-3d/dist/` 整个文件夹拖进去（里面只有一个 `广外校园向导.html`）；
3. 部署完成后把 `xxx.vercel.app/广外校园向导.html` 作为作品链接。

> 中文文件名会变成 URL 编码，介意的话把文件重命名为 `index.html` 再拖，访问路径就是根域名。

### 方案 B：GitHub Pages

1. 新建仓库 → 上传 `dist/广外校园向导.html`，重命名为 `index.html`；
2. Settings → Pages → Source 选 `main` 分支根目录；
3. 链接形如 `https://<用户名>.github.io/<仓库名>/`。

### 方案 C：校内服务器 / 任意静态托管

`广外校园向导.html` 是纯静态单文件，放到任何能返回 HTML 的服务器目录下即可，无需 Node、无需后端。

## 三、上传前自检（照着点一遍）

- [ ] 双击本地文件能打开，**3D 模型正常显示**（不是灰色方块阵）；
- [ ] 点一栋楼，底部弹出信息卡，有"官方来源"链接；
- [ ] 选起点/终点能画出黄色路线，状态栏显示距离和"经地下隧道穿行"；
- [ ] 右下角 AI 面板能回答"从文采园怎么去图书馆"；
- [ ] **断网**再问一次，徽章变"离线 · 本地规则"，仍能画出路线（这是公网演示的保险）；
- [ ] 手机上打开不崩（列宽会自适应，AI 面板可能盖住地图，可折叠）。

## 四、链接怎么交更稳

建议在提交时同时给：

1. **公网作品链接**（单文件版，任何人可打开）；
2. **Dify 应用链接** `http://172.17.1.46/chat/uJIqVGKRsnkz7GY8`（评委在校内网时可体验完整智能体）；
3. 一句说明："作品前端为纯静态页面，AI 能力由 Dify Chatflow 提供；如无法访问校内 Dify，前端会自动降级为本地规则模式，功能不中断。"

这样即使评委在公网，也能看到完整作品；如果评委在校内网，还能看到智能体的真实调用。
