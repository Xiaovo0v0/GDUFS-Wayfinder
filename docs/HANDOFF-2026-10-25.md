### 2）定位「我的位置」

- 入口：左侧面板「📍 我的位置」，再点一次取消。
- `geo.js`：`navigator.geolocation.watchPosition` → WGS84 投影到校园本地坐标（x 西为正、z 北正；`KX = 111320·cos(lat0)`、`KZ = 110540`）。南校 `meta.origin_wgs84` 已配准；北校没有经纬度，按钮会提示不支持。
- `app.js`：精度圈半径 = GPS 上报的 `accuracy`；画蓝点 + 标签；`nearestNode` 贴最近路网节点（实测偏差 8.8 m），作为临时 `place` 参与 Dijkstra；起点下拉多一项「📍 我的位置」（value=-2）；连续定位移动 ≥3 m 才重算路线，首次或移动 >60 m 才推镜头，避免抢视角。
- GCJ-02：部分国产浏览器返回高德坐标，`?geo=gcj` 先反算；点落在校界外 80 m 会提示。
- 对话层（`navigator-ui.js`）：问「我在哪 / 附近有什么」走本地规则秒回；问「我这里怎么去图书馆」时，给 Dify 的 query **前置**一句「我现在在X附近。」，让 Dify 的算路节点自然得到 `from=最近地标, to=目的地`，拿回动作后前端再用**真实定位点**重算。**Dify 12 个节点一个都没改**。
- 无 GPS 的演示/截图：`?ll=23.06829,113.3946,15`。
- 验收：`tools/check_locate.mjs` 用 CDP 伪 GPS + `Browser.grantPermissions`，http 9 项、`--file` 17 项全过。
- 方案、坑、答辩问答：见 [`docs/19`](19-定位我的位置-实现方案.md)。

### 3）手机端适配

- 断点 `≤760px`（旧的 860 已删除），桌面布局原样保留；`#dock` 用 `display:contents` 包住面板与建筑卡。
- 顶栏通栏 + 底部抽屉：默认收起，只留标题 + 一行摘要（起终点 / 距离 / 状态）；点标题条展开；表单与图例分开展开；建筑卡出现时自动收起图例。
- 语心：默认收起，顶栏头像按钮打开成浮层，✕ / Esc 关闭；带 `?q=` 深链时自动打开。
- 安全区：`env(safe-area-inset-*)` 让开刘海 / 底部小白条；iOS 软键盘用 `visualViewport` 把抽屉与输入框抬到键盘上方（`--kb`）。

- `mobile_check.mjs` 覆盖 430×932（中/英，默认/展开/路线/建筑卡/语心/漫游/深链）、360×640、320×568、320 英文、768×1024 平板、844×390 横屏、1440×900 桌面；断言“不横向溢出 / 浮层不互相压住 / 桌面不出现收起条”。

## 六、别推翻的决定

| 决策 | 理由 |
|---|---|
| 动作契约：模型只输出 `{intent, from, to, answer, card}` JSON，渲染由前端做 | 避免“AI 说往东、地图不动”；同一套智能体可被网页/小程序复用 |
| 双通道降级：Dify 连不上就切本地规则 | 断网也能演示；模型下线不会让作品不可用（已实测） |
| 交付形态选「本地客户端应用」 | `172.17.1.46` 是校内私有地址，评委在校外打不开 |
| **定位不绕 Dify**，只在“定位之后的语言层”用它 | GPS 是每秒变化的前端状态；模型算坐标必错、还多 4–5 秒延迟 |
