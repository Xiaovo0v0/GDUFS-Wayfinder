# 双校区经纬度锁定（2026-11-01）

用公开底图把 `gdufs-3d` 的校园模型钉到经纬度上：南校区（大学城）复核既有原点，
北校区（白云山）第一次拿到原点。**结论先放这里，方法、残差、复现命令在下面。**

## 二、`map.jiqrxx.com/map/5051.html` 到底是什么

那页**没有**钉住广外任何一个在用校区：

- 页面只吐四个变量：`jd="113.25563"`、`wd="23.234015"`、`z=12`。这个点在
  23.234 N、113.2556 E，在白云山校区**西北约 4.6 km**、离大学城校区约 19 km，
  对应旧「大朗校区」一带——是通用模板填的老坐标，不是现在的校区。
- 它本身是个 Leaflet 1.9.1 壳子（`/pluging/main.js` + `/static/map.js`），
  底下挂三套公开瓦片：腾讯 `rt*.map.gtimg.com`（GCJ-02）、
  `server.arcgisonline.com` ArcGIS World Imagery（WGS84）、天地图 `vec_w/img_w`（tk 混淆）。

所以"用它锁定"的正确姿势不是抄它的坐标，而是**抄它的瓦片**：本仓库的
`tools/lock/` 直接拉这些公开瓦片做拼接，再自己算配准。实测可达性：

| 源 | 结果 |
| --- | --- |
| ArcGIS World Imagery（WGS84，无偏移） | 200，JPEG，z18 在 23.2°N 为 0.549 m/px → **主用** |
| 高德注记 `webrd0{1-4}.is.autonavi.com`（GCJ-02） | 200，中文楼名，用于核对校区范围 |
| 天地图（页面里的三套之一） | tk 失效，418 |
| 腾讯 `realtimerender` | 返回纯白空瓦片（被拦） |
| `tile.openstreetmap.org` / `nominatim` / `api.openstreetmap.org` | 本机 DNS 解析失败 |
| Overpass（`overpass-api.de`） | 可用，kumi / private.coffee / osm.jp 常 504，脚本按序重试 |

## 三、方法：四种解互相校验，最后只取纯平移

`geo.js` 的 `project()` 是纯平移（`x = −(lon−lon0)·KX`、`z = (lat−lat0)·KZ`），
存不进旋转和尺度，所以配准必须交出一个"只平移"的原点。四种解法：

| 方法 | 脚本 | 结果 | 残差 | 判定 |
| --- | --- | --- | --- | --- |
| 同名建筑最小二乘（固定尺度） | `fit_north.py` | `23.20382514, 113.28631414` | 45.1 m / 最大 85.4 | 采纳为交叉验证 |
| 同上 + 相似变换（带旋转尺度） | `fit_north.py --similarity` | scale 0.9255、rot −4.54° | 49.6 / 127.2 | 更差，弃 |
| 建筑足迹 IoU（各向异性） | `register_iou.py --aniso` | `23.20394754, 113.28576474` | IoU 0.205，但同名建筑均值 61.6 m、整体东移 55 m | 田径场好、楼全错，**否决** |
| 路网 ICP（自由相似变换） | `register_icp.py` | θ −1.5373°、s 0.95248 | 中位数 8.86 m | 只能当参考 |
| **路网 ICP（锁死旋转/尺度）** | `register_icp.py --fix-rot --fix-scale` | **`23.20385672, 113.28631562`** | 中位数 11.48 m | **采用** |

选它的理由：它与"9 栋同名建筑最小二乘"（方法一，完全独立的数据和算法）
独立收敛到相距 4 m 的同一点；且它满足 `geo.js` 只平移的硬约束。

顺带验证了"要不要给 `geo.js` 加旋转"：只放旋转、把尺度锁回 1，解出 θ −0.67°、
中位数 **11.04 m**（对比纯平移 11.48 m）——几乎没改善。**误差不来自朝向**，
是平面图本身的概括误差，所以不值得为它改投影公式。

南校区用同一套 ICP 复核：自由解 θ −0.94°、scale 0.998、平移≈0，
中位数 0.39 m —— **原有 origin 经受住了检验**，不用改。唯一遗留是那 0.94°
没被建模，800 m 尺度上远端差 ±13 m，属于可接受范围（见"已知局限"）。

## 四、落了什么进代码

1. `gdufs-3d/north-data.js` → `meta.origin_wgs84` 由 `null` 改为
   `{"lat":23.20385672,"lon":113.28631562}`，并新增 `meta.georef` 记录方法、
   控制数据、残差、底图、日期（下次谁想重算，字段就在那儿）。
   写入脚本：`tools/lock/apply_georef.py`（幂等，会顺手校验整份文件仍是合法 JSON）。
2. `gdufs-3d/geo.js` → 文件头「前提」里那句"北校区没有经纬度，按钮不可用"改成
   现状；`TEXT.north` 兜底文案从"北校区…暂不支持"改成通用说法。
   **没有改任何逻辑**——`geo.js` 本来就是读 `META.origin_wgs84`，
   原点一有，"◎ 我的位置"按钮自动可用，`?ll=lat,lng` 调试参数也跟着生效。
3. 出图（都在 `artifacts/lock/`）：
   - `two_campus_sheet.png` —— 三栏交付图（北校 / 南校 / 全城位置）
   - `north_final.png` —— 北校：影像 + 模型边界（青）+ 模型建筑（紫）+ OSM 足迹（绿）
   - `south_final.png` —— 南校同款，边界与建筑几乎重合
   - `two_campus.png` —— 全城：两校区各画 430 m 圆环 + 连线

## 五、复现

```powershell
# 1) 北校：抓 OSM（Overpass 常 504，脚本自动换镜像）
node tools\lock\fetch_osm.mjs --bbox 23.190,113.275,23.215,113.300 --out artifacts\lock\osm_north2.json
# 2) 路网 ICP 纯平移解
python tools\lock\register_icp.py --data gdufs-3d\north-data.js --osm artifacts\lock\osm_north2.json `
  --lat0 23.2038 --lon0 113.2863 --bbox 113.2810,23.1995,113.2905,23.2090 --fix-rot --fix-scale
# 3) 同名建筑残差
python tools\lock\check_fit.py --data gdufs-3d\north-data.js --osm artifacts\lock\osm_north2.json `
  --lat 23.20385672 --lon 113.28631562 --bbox 113.2810,23.1995,113.2905,23.2090
# 4) 叠图（z18，0.549 m/px）
python tools\lock\project.py --data gdufs-3d\north-data.js --out artifacts\lock\overlay_north.json
python tools\lock\tiles.py --bbox 113.2812,23.1997,113.2899,23.2086 --z 18 `
  --out artifacts\lock\north_final.png --overlay artifacts\lock\overlay_north.json
# 5) 三栏交付图
python tools\lock\make_sheet.py
```

`tools/lock/` 下的脚本全是纯标准库 + numpy/scipy/Pillow，注释用 ASCII 写，
避免本机 PowerShell 5.1 按 GBK 读 UTF-8 的老坑（见 `AGENTS.md` 硬规则 1）。

## 六、已知局限（别当成"精确到米"）

1. **北校 ±40 m 是校园级精度**，单栋楼 30~80 m 的散布源于平面图概括，
   想再准只能重新测绘或逐栋在影像上人工描。
2. **边界不是围墙**：`north-data.js` 的 `meta.note` 写明边界是建筑群凸包外扩
   26 m，面积 0.374 km²。叠图里边界和真实园区轮廓基本吻合，但不能当校界证据。
3. **南校 0.94° 的旋转没建模**，纯平移在远端有 ±13 m 的系统性偏差。
4. **本机浏览器跑不起来**：Edge 在 DSH 沙箱里创不了 mojo 命名管道
   （`platform_channel.cc: Check failed … 0x5`），`tools/smoke.mjs` / `lint_ui.mjs`
   这次没跑成。改动只碰了数据和一个注释、两句文案，`node --check` 两项均过，
   `north-data.js` 整份仍是合法 JSON；但仍建议在能开浏览器的环境补跑一次冒烟。
