## 三、视觉升级（"样式过于粗糙"）

### 3.1 立面：从"纯色盒子"到"有开窗的墙"

- 旧：`ExtrudeGeometry` 直接挤出，整栋一个纯色 `MeshStandardMaterial`。
- 新：按每条轮廓边生成**带 UV 的墙面四边形**，1 张程序化立面贴图 = **3.6 m 开间 × 3.6 m 层高**，所以窗格密度与楼高、楼长自动匹配。
- 四种立面原型（依据官方照片）：
  | 类型 | 做法 | 依据 |
  |---|---|---|
  | 教学/实验楼 `ribbon` | 米白瓷砖 + 红褐砖柱 + 连续横向带窗 | 钟楼照片 `g_building.jpg`、官方鸟瞰图 |
  | 图书馆 `curtain` | 红褐石材分格 + 青绿玻璃幕墙 | 图书馆夜景 `g_lbnight.jpg` |
  | 宿舍 `punch` | 暖米色墙面 + 白色窗台方窗 | 官方鸟瞰图 |
  | 食堂 `large` | 砖红墙垛 + 通高玻璃 | 鸟瞰图 + 食堂资料 |
  | 体育馆 `panel` | 浅灰金属板 + 条形高窗 | 鸟瞰图 |

### 3.2 屋顶：女儿墙 + 屋顶设备

- 每栋加 **0.9 m 女儿墙**（向外 0.18 m，避免 z-fighting），屋顶不再"一刀切"。
- 面积 > 1200 ㎡ 的建筑按 id 哈希**稳定生成 2–4 个屋顶设备箱**（空调机组/水箱），不会每次刷新乱跳。
- 屋顶色统一改为冷灰（`#6a6f73`），与米黄墙身拉开层次。

### 3.3 环境：行道树 + 校门构造

- **1 008 棵树**：沿道路两侧每 15 m 交替种一株 + 绿地随机 700 株，自动避让建筑轮廓与校门；用 `InstancedMesh` 渲染，只占 2 个 draw call。
- 校门从"一个红色圆盘"升级为**双门柱 + 横梁 + 地面标识**的门楼构造。

### 3.4 色彩管线修正（这是个隐蔽的坑）

Three.js r128 没有色彩管理，`new THREE.Color(0x6a6f73)` 会被当作**线性值**直接进 shader，导致所有纯色材质比设计值亮一大截（屋顶发白、树发灰）。本次加了 `col()` 帮助函数统一做 `convertSRGBToLinear()`，并重新标定了灯光（`ACESFilmic` + 太阳 1.0 / 半球 0.40 / 环境 0.12）。

## 五、还没解决的（按优先级）

1. **实验楼 A–E 的区号方向**：现在是按几何等分 + 早期读图结果（东北端 E → 西南端 A）标注，但官方示意图只给"⑪ 实验楼 A–E 区"整体，没有逐栋字母。**需要用官方平面图配准后逐一核对**。
2. **2 号门、4 号门坐标**：官方平面图上有，但尚未配准落点（见 §一）。
3. **教学楼 A/B/C/D/F/G 层数**：官方无数字，模型仍按 5 层估算。
4. **B8 学术报告厅、行政办公楼**：层数/面积/外观全缺。
5. **宿舍/食堂外观**：只查到座位数与编号，外墙颜色无官方文字记载，现按鸟瞰图取色。
6. **钟楼**：官方确认它是"南校区名片"（方形塔、红褐+米白面砖、四面圆形钟面、平顶带栏杆），但**具体归属哪栋、坐标在哪**未查到，暂未建模。
