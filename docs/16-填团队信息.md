# 填团队信息（最后一步）

> 这一步只能由你做，因为涉及姓名、学号、联系方式。
> 两种方式，选一种，**30 秒搞定**。

---

## 方式一：跑一条命令（推荐）

在 `C:\Users\86134\Desktop\gdufs` 打开 PowerShell：

```bash
python tools/fill_team.py --team "你的队名" `
  --leader "张三|信息科学与技术学院|20241003008|13800000000|zhangsan@gdufs.edu.cn" `
  --member "李四|信息科学与技术学院|20241003009|13900000000|lisi@gdufs.edu.cn"
```

- 每个字段用 `|` 分隔，顺序是：**姓名 | 所在院系 | 学号 | 联系方式 | 电子邮箱**
- 成员最多 4 个，`--member` 可以重复写
- 只填姓名也行，其余留空：`--member "李四"`

跑完会自动重新生成 `deliverables/广外校园向导-初赛设计方案.docx`。

## 方式二：交互式

```bash
python tools/fill_team.py
```

按提示一项一项输入，回车保持原值，成员输入空姓名就结束。

## 方式三：直接在 Word 里填

打开 `deliverables/广外校园向导-初赛设计方案.docx`，第 1 页表格：

| 位置 | 填什么 |
|---|---|
| 第 1 行 | 团队名称（现在是 `＿＿＿＿＿＿`） |
| 第 3 行 | 负责人：姓名 / 所在院系 / 学号 / 联系方式 / 电子邮箱 |
| 第 5–8 行 | 团队成员，最多 4 人，没人的行留空 |

---

## 填完之后

1. 重新打包（可选，如果之后要发整包）：

```bash
node tools/build_single_file.mjs
```

2. 核对第 1 页三项：
   - [ ] 团队名称已填
   - [ ] 负责人 5 项已填
   - [ ] 参赛主题是「生活服务」

3. 打开看一眼，确认没有超出页边距

- 团队信息存在 `deliverables/team.json`，**已经加进 `.gitignore`，不会被提交**，也不会出现在任何公开的地方
