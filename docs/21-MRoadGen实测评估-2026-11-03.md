# MRoadGen 实测评估（2026-11-03）

对象：`MaartenNauta-Pathtrace/MRoadGen` v1.1.0（CC0），Blender 5.1 几何节点路网生成器。
目的：判断它能否用来改善 `gdufs-3d/` 的道路建模；不是看演示图，是把**我们自己的路网数据**灌进去跑一遍。

## 结论

1. **不能当生产管线替换**。它的输入是「一堆中心线 + 一个全局路宽」，输出是 Cycles 级渲染资产；
   我们需要的路口拓扑、逐条路宽、运行时可算路高亮，它都不提供。
2. **路口是硬伤**。同一条 mesh 里 T 形/十字相接，它只在交点处把两条带子切断然后各走各的，
   留下缺口（见 `artifacts/blender/real_junction_closeup.png`）；把支路多伸 5 m 冲过中心，
   得到的是尖刺穿插而不是圆角（`real_junction_overshoot.png`）。南校 74 个路口（4 臂 53、6 臂 4、8 臂 1），
   靠手工摆路口不现实。
3. **材质出不了 Blender**。沥青噪声、虚线中心线、边线都挂在程序化节点和自定义属性上；
   实测导出 GLB 44 KB，回读只剩 `DefaultMaterial`、零张贴图（`tmp/export_glb.py`）。
4. **在总览视距下没有优势**。同一份数据、同一个机位渲染（`compare_mroad.png` 右），
   因为缺建筑/人行道/树，观感远不如现在的前端（左）。它的价值只在**近景**：路缘、虚线、沥青颗粒。

## 实测记录

环境：`tmp/blender5/blender-5.1.2-windows-x64/blender.exe`（便携版，5.1.2，2026-05-19 构建）。
**没有动** `C:\Program Files\Blender Foundation\Blender 4.5`，建筑管线不受影响。
MRoadGen 资产：`tmp/MRoadGen.V1.1.0.blend`（105 MB，release `v1.1.0-blender5.1`；
README 写 5.0，实际发布资产要求 5.1）。

输入数据的两个硬约束（踩过才知道）：

- 中心线必须是**网格边**，且每个点要有 `crease_vert = 1.0`；缺这个属性宽度会塌成零。
- `Viewport` 菜单要设成 `Preview (Fast)`、`Render` 设成 `Final (Slow)`；否则视口求值走错分支，
  得到带裙边的怪几何。真正的渲染（`bpy.ops.render.render`）才会走 Final。

导出脚本：`tmp/export_roads.mjs`（南校 101 条 / 645 点 / 74 路口 →
`artifacts/blender/roads_south.json`）、`tmp/real1.py`（全网俯视）、`tmp/real2.py`（路口近景）、
`tmp/real4.py`（总览 + 路口补面）。

数据：

| 项 | 数值 |
| --- | --- |
| 参与生成的道路 | 67 条（去掉 footway / steps / path） |
| 输入中心线 | 561 点 / 493 边 |
| 快速模式输出 | 939 顶点 / 491 面（无材质） |
| GLB 导出 | 44,544 B；回读 1 个 `DefaultMaterial`、0 张贴图 |
| 渲染耗时 | 1600×1000 / 64 spp / CPU ≈ 30 s |

## 它确实做对的地方

- 宽度方向的路缘收边、虚线中心线的间距和粗细，近看是「像路」的（`real_junction_closeup.png`）。
- 曲线平滑（Subdivision Surface）比我们现在按折点直接扫掠要顺，尤其是弯道内侧。
- 材质里的沥青颗粒与边线是同一张 UV 驱动的，没有接缝。

## 对现有前端的三条可用改进（不依赖 Blender）

按性价比排序，都能在 `gdufs-3d/app.js` 里做，不需要新依赖：

1. **路口补面加圆角 + 标线**：`renderJunctions`（`app.js:1487`）现在铺的是纯沥青盘。
   用 `build_junctions.py` 已有的 `ROUND=0.6` 圆角，再按 `j.arms` 给 4 臂正交路口加停止线，
   多岔斜交仍然不加（第四轮否掉的原因还在）。
2. **虚线改几何**：`roadTexture`（`app.js:1193`）把虚线烘在 64×256 贴图里，弯道会拉长。
   改成沿中心线每 9 m 一个 3 m 小面片，弯道和路口都能正确断开。
3. **路缘只在近景出现**：给 ribbon 加 0.13 m 的立面，按相机距离做 LOD，
   总览视距（约 1.24 m/px）下直接跳过——不然白增三角面。

工作量：1 与 2 各半天，3 一天（含截图回归）。

## 不建议做的事

- 用 MRoadGen 离线烘一张全校 GLB 代替运行时：丢材质、丢逐路宽、丢算路高亮，还要重做 74 个路口。
- 为了这个工具把建筑管线迁到 Blender 5.x：现在 4.5 跑得好好的，5.x 没有收益。
